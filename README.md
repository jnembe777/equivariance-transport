# How far can symmetry help? — Companion repository

Code, numerical experiments and figures accompanying the paper:

> **How far can symmetry help? Phase transitions and symmetry selection in
> sparse functional data analysis.**
> Jocelyn Nembé, Laboratory of Engineering Applied to Business Management,
> Libreville, Gabon.
> arXiv:2608.27055 — submitted to *Bernoulli* (main paper + supplement).

The paper studies the sharp phase transition of the covariance surface in
sparse functional data analysis at the critical sampling intensity
m*_n ≍ n^{1/(2β)}, quantifies what a symmetry (equivariance) assumption
buys, and closes the minimax gap at the stationary endpoint via positive
spectral thresholding, with rate (nm²)^{-(2β+1)/(2β+2)} + 1/n.

## Contents

```
scripts/               numerical benchmarks and real-data analysis (Python)
figures/               figures of the main paper
figures/supplement/    figures of the Supplement (Section S.8 campaign)
results/               numerical outputs (JSON)
data/                  data provenance (no raw data stored; see data/README.md)
```

## Scripts ↔ results in the paper

| Script | What it does | Output | Paper |
|---|---|---|---|
| `Gap_bench_sanity.py` | Sanity checks: dyadic-block mass lemma (β = 1) and bias/variance scales of the spectral estimator λ̂ₖ (n = 400, m = 8, 40 reps) | console tables | Section 7; proofs in Supplement S.10 |
| `Gap_bench_race1.py` | Rate race, single member: thresholded spectral estimator vs oracle-bandwidth smoother; empirical slopes vs targets (2β+1)/(2β+2) and 2β/(2β+1) | console | Section 7, Theorem 7.2 |
| `Gap_bench_race2.py` | Rate race over a two-member family (sup-risk); separation of the two floors n^{1/(4β)} vs n^{1/(4β+2)} | console | Section 7, Corollary 7.3 |
| `Art1_analyse_stationnaire.py` | El Niño data: hold-out risk of the q-fold symmetrized estimator targeting the stationary component Π₁₂C, 60 splits; saturation threshold q_sat vs bandwidth h | console table | Section 10.3 |
| `Art1_analyse_elnino.py` | El Niño data: full analysis (refusal on the full covariance, gains on the stationary component); produces the figure and every number quoted in the text (0.206 → 0.111, 46 % gain, +12 % refusal, q_sat = 3 → 2) | `figures/fig_elnino.pdf`, `results/elnino_numbers.json` | Figure 3, Section 10.3 |

All random experiments use fixed seeds (`numpy.random.default_rng(0)` or
`(1)`), so every number and the figure are reproducible bit-for-bit.

## Figures

- `figures/fig_elnino.pdf` (Figure 3 of the paper) is **generated by**
  `scripts/Art1_analyse_elnino.py`.
- `figures/fig_diagramme_phases.pdf` (Figure 2, empirical phase diagram at
  β = 3/2, n = 500) and the six figures in `figures/supplement/`
  (threshold and plateau, hold-out selection, naive-vs-mechanistic
  crossings, effective-dimension scans and n-scaling) come from the
  simulation campaign documented in Section S.8 of the Supplement, and are
  provided here as static assets of that campaign.

## Reproducing

Python ≥ 3.10.

```bash
pip install -r requirements.txt
bash run_all.sh          # runs everything, ~ a few minutes
```

or run any script individually from `scripts/`:

```bash
cd scripts
python Art1_analyse_elnino.py   # writes fig_elnino.pdf + elnino_numbers.json
```

`run_all.sh` moves the generated figure to `figures/` and the JSON to
`results/`.

## Data

The real-data section uses the classical **El Niño sea-surface temperature
dataset** (monthly SST, 1950–2010) as shipped with `statsmodels`
(`statsmodels.datasets.elnino`). No download and no local data files are
required; see `data/README.md` for provenance and licensing.
